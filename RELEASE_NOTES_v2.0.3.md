# v2.0.3

This maintenance release replaces the ZIP container used for the public
archive. Internal file paths now use forward slashes, as required for portable
extraction across Windows, Linux, and macOS tools.

The archived data, scripts, numerical results, figure sources, and reported
claims are unchanged from version 2.0.2. No scientific content was added,
removed, or recalculated.

The public archive contains code, archived data, solver records, and figure
sources. The manuscript, LaTeX source, cover letter, editorial correspondence,
and Supplementary Appendix S1 are not included.
